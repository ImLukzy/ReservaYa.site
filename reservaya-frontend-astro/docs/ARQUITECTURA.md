# Arquitectura

Resumen de arquitectura del proyecto Educlook Web.

## Stack
- Astro
- Tailwind CSS
- TypeScript/JavaScript

## Estructura
- `src/layouts`: layouts base
- `src/components`: componentes reutilizables
- `src/sections`: bloques de pagina
- `src/pages`: rutas
- `public`: assets estaticos

## Principios
- SEO tecnico
- Rendimiento alto
- Codigo mantenible y escalable
