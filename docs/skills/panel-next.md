# SKILL: Next público y panel (`apps/web`)

Usar para rutas, componentes y clientes de API. Las dos superficies comparten implementación en `components/ui`, con `apariencia="publica"` cuando corresponde.

## Reglas

1. Next 16: consultar `apps/web/node_modules/next/dist/docs/` antes de usar una API. `proxy.ts` exporta `proxy`; `npm run dev` conserva `next dev --webpack` por las rutas agrupadas en Windows.
2. Cookie HttpOnly `token` emitida por API; servidor usa `requireAuth`/`requireRole`. El cliente no lee ni guarda JWT. Layout público sin guarda de sesión; proxy limitado a zonas protegidas.
3. Servidor: `server-fetch.ts` (`serverFetch`/`getJson`, server-only) → `api.ts`/`b2b-api.ts`. Cliente: `http.ts` (`apiRequest`) → `api-client.ts`/`b2b-client.ts`. Tipos: `api-types.ts`; cliente importa solo tipos del servidor. Una función tiene una sola implementación.
4. Errores lanzan `ApiError`; páginas usan `crearCarga` y `AvisoCarga`. No ocultar fallos con arrays vacíos. Permisos y destino por rol en `permissions.ts`; `returnUrlSeguro` valida retorno local. Datos de otra sede no disponibles son BLOQUEO-API, sin workaround.
5. Páginas server components por defecto. `'use client'` solo para estado/efectos. No setState síncrono en el cuerpo de useEffect; derivar en render, key para resetear o callback async. Listeners, observers y solicitudes tienen cleanup/cancelación.
6. API y uploads por mismo origen mediante rewrites privados a BACKEND_URL. Nada de host API directo, JWT o secretos en cliente. Requests JSON y FormData usan el mismo helper; no forzar Content-Type JSON en multipart.
7. TypeScript tipado, sin `any` ni HTML construido con datos. Usar textContent/createElement/replaceChildren y guardas DOM. Sin datos personales/mocks reales hardcodeados, alert o logs de secretos; errores visibles.
8. Conservar metadata, canonical, OG, JSON-LD, robots/sitemap y las dos fuentes locales OFL de la spec 54 (Instrument Sans para leer, Anybody para titulares y cifras), declaradas en `<html>` para que `--font-sans`/`--font-display` resuelvan en `:root`. GA opcional sin doble pageview y cero solicitudes en reset-password; fragmento de recuperación borrado del historial, sin token en telemetría.
9. Tokens CSS de globals.css/public.css; CSS público aislado bajo .public-site, raíz 16 px, fuentes locales. Tablero con filas sin radio; público usa rounded-control/surface/full, max-w-page y max-w-texto. Píldoras y campos públicos conservan radio completo. Sin sombras duras ni bordes gruesos negros: `card-tactil`/`btn-tactil` son borde fino `cal` + `shadow-suave*`; controles con borde `borde` (≥3:1). No cambiar clases del panel al ajustar variante pública.
10. Paleta única verde (spec 53, enriquecida en 54). Panel claro: texto blanco sobre `cesped` #17804a (4.97:1) o más oscuro. Sitio público oscuro (spec 54, parentesco): `.public-site` redefine los tokens base (`sillar` #06120a fondo, `tiza` #0c1d13 superficie, `basalto` texto claro, `cesped` = verde vivo #22c55e); las clases no cambian. Sobre verde vivo el texto va oscuro (`text-tiza` dentro de .public-site, o `.btn-vivo`: 8.39:1), nunca blanco (2.3:1). Texto sobre fotos con velo usa `text-blanco` (fijo), no `text-tiza`. `reflector` = `cesped-vivo` #22c55e para verde de texto sobre noche. En public.css usar `var(--token)`, nunca `var(--color-token)` (se resuelve en :root y no hereda el tema oscuro). Amarillo/rojo solo para estado. Degradados solo como velo de noche sobre fotos (`.escena__velo`, `.banda-foto`, `.mosaico-deporte`, `.ficha-viva`, `.cuenta-velo`), con ≥0.7 de opacidad bajo cualquier texto, más el resplandor y la cuadrícula de `.vitrina` (único fondo decorativo) y las máscaras de desvanecido del mosaico y la cinta. Sin backdrop blur, glifos/emoji como iconos ni mayúsculas con espaciado decorativo (`.eyebrow` va en minúsculas de frase y solo cuando aporta contexto). Titulares grandes con `.titular` o `.titulo-seccion` (Anybody estrecha); h2 pequeños en ancho normal.
11. Motion spec 46: bloque generado en globals.css mediante `node scripts/motion-tokens.mjs --write`, sin edición manual. Resorte k=400,c=30,m=1; transform usa --dur-resorte/--ease-resorte. Opacidad/color/sombra usan --dur-toque/--dur-entra y --ease-salida; no curvas/duraciones literales. Bucles con `/* motion: ambiental */`, reduced-motion respetado.
